# Icare HMIS

A healthcare management information system built with React, Vite, TypeScript, and Tailwind CSS.

## Overview

This project provides a modern clinical and administrative dashboard for healthcare operations, including patient workflows, billing, reporting, and care management.

## Getting started

### Prerequisites

- Node.js 18+
- npm or bun

### Install dependencies

```sh
npm install
```

### Run locally

```sh
npm run dev
```

The app will be available on the configured Vite development server port.

## Available scripts

- `npm run dev` - start the development server
- `npm run build` - create a production build
- `npm run preview` - preview the production build
- `npm run test` - run the test suite

## Project structure

- `src/` - application source code
- `public/` - static assets
- `vite.config.ts` - Vite configuration

## Notes

This project is developed as a custom application for your organization and is not tied to any external no-code platform branding.
